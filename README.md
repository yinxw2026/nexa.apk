# nexa.apk

A local AI chat client that can connect to OpenAI-compatible APIs, Anthropic, or Google Gemini.
It’s tiny—only a bit over 90 KB.

Recently, I felt that AI clients on the market were too bloated, often tens of MB. So I built one from scratch myself using AI. It’s only 90 KB, has no ads, stores everything locally, and supports connecting to various APIs. It’s open-sourced on GitHub—I’d appreciate a star and any bug reports!

This is the first version, so there may be plenty of bugs. Feel free to roast me on the GitHub Issues page and help me improve it.
