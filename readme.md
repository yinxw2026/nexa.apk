# Nexa 使用文档

Nexa 是一个本地优先的通用 AI 对话客户端。它不绑定任何服务商，你可以接入任意 OpenAI 兼容接口、Anthropic 或 Google Gemini，并在同一个应用里切换使用。

所有对话与密钥只保存在本机。

---

## 一、快速开始

1. 打开应用，右上角是**新建对话**，左上角是**历史对话**。
2. 点击右上角加号进入设置，选择 **供应商 → 添加供应商**。
3. 从内置预设里挑一个（例如 DeepSeek），填入 **API 密钥**，保存。
4. 回到对话页，点标题旁的模型胶囊选择模型，就可以开始聊天了。

没有密钥时可以点供应商页面里的 **测试连接**，确认地址与密钥是否正确。

---

## 二、配置供应商

一个「供应商」就是一套 API 端点配置：

| 字段 | 说明 |
| --- | --- |
| 名称 | 显示用，例如 DeepSeek、公司内网模型 |
| 接口类型 | OpenAI 兼容 / Anthropic / Google Gemini |
| Base URL | 服务地址，例如 `https://api.deepseek.com` |
| API 密钥 | 加密保存在本机 |
| 模型列表 | 每行一个模型名，也可点「从接口拉取模型」自动获取 |
| 参数风格 | 控制思考强度参数如何发送，见第四节 |
| 附加请求体 | 可选，原样合并进请求体的额外 JSON |

Base URL 只需要填到版本号之前，路径由应用补全：

- OpenAI 兼容：`https://api.deepseek.com` → `.../v1/chat/completions`
- 已经带 `/v1` 也可以：`http://192.168.1.2:1234/v1` → `.../v1/chat/completions`
- Anthropic：`https://api.anthropic.com` → `.../v1/messages`
- Gemini：`https://generativelanguage.googleapis.com`

内置预设覆盖 DeepSeek、OpenAI、Kimi、智谱 GLM、通义千问、硅基流动、Claude、Gemini，以及本机 / 局域网模型。

## 三、对话

- **新建对话**：右上角加号。
- **历史对话**：左上角列表按钮，支持按标题搜索，长按可重命名或删除。
- **重新生成**：助手消息下方的刷新按钮。
- **停止生成**：生成过程中发送按钮会变成停止按钮。
- **代码块**：右上角有复制按钮；回答支持标题、列表、表格、引用、代码块等常见 Markdown 语法。
- **思考过程**：推理模型的思考内容显示在回答上方，只保留最新 4 行并自动向上滚动，顶部渐隐；点右侧「展开」可查看完整内容。即使本轮因检索轮数用尽而结束，思考过程与已生成内容也会完整保留。
- **统计**：每条回答生成后，会在下方显示本次消耗的总 Token 数与耗时。
- **上下文轮数**：设置里可调整每次请求携带多少条历史消息。
- **语言**：抽屉左下角的「中/En」按钮可切换界面语言。

## 四、思考强度

输入框上方的图标可打开思考强度面板，用滑杆在五档之间切换，下方还可以设定**自定义推理预算**：

| 档位 | 预算 | 适用场景 |
| --- | --- | --- |
| 关 | 0 | 直接回答，最快最省 |
| 低 | 2048 token | 日常问答、简单改写 |
| 中 | 4096 token | 一般推理题 |
| 高 | 8192 token | 复杂推理、数学、长代码 |
| 极高 | 16384 token | 极难问题 |
| 自定义 | 自定 | 精确控制思考开销 |

不同接口接受的字段不一样，所以在供应商设置里可以指定**参数风格**：

- 跟随模型：模型名含 `reason`、`think`、`o1/o3`、`glm-4.5`、`r1` 等关键字时才发送
- reasoning_effort：发送 `reasoning_effort: low/high`
- thinking 预算：发送 `thinking: {type: enabled, budget_tokens: N}`
- 两者都发：同时发送两种字段
- 都不发：完全不带思考参数，适合会因未知字段报错的严格接口

设置页里会**实时预览**当前请求将要附加的内容。接口报 400 并提示未知参数时，把风格改成「都不发」即可。

## 五、联网搜索

输入框上方的地球图标可开启联网搜索。开启后，`web_search` 工具的定义会随请求一起发送给模型，**由模型自己判断要不要搜索、用什么关键词**；模型发起调用时，界面会显示浅绿色呼吸点与"正在联网搜索……"，应用执行检索后把结果交回模型继续作答。

设置里可以调整两项：**搜索结果条数**（1 到 10）与**最多检索轮数**（1 到 10，默认 4）。轮数越多越费 token，因为每一轮都要重发完整对话；模型达到上限时本轮会正常收尾，思考过程与已生成内容都会保留，不会丢失。

在"指令注入"页还有一个 **「联网时告知 AI 最多调用次数」** 开关（默认开启）：打开后会在系统提示词末尾附加一句说明，把当前的轮数上限告诉模型，帮助它一次性规划好关键词。这句说明只发给模型，不出现在输入框里。

此功能需要模型支持函数调用（function calling）；若接口不支持，请关闭搜索开关。

支持的服务及其可用性：

| 服务 | 可用性 |
| --- | --- |
| **Bing** | 国内直连，无需密钥，返回 10 条结果 |
| **Baidu** | 国内直连，抓取解析，结果质量一般 |
| Tavily | 需要 API 密钥 |
| SearXNG | 需要自建实例，且允许 JSON 输出 |
| DuckDuckGo | 需要海外网络 |
| Wikipedia | 需要海外网络 |

在 **设置 → 搜索服务** 里可以切换并测试检索效果。

## 六、附件

输入框左侧的回形针按钮可以一次选择多个文件：

- 点击回形针后可选择 **拍摄 / 照片 / 文件**（相机 / 图库 / 内部存储）
- 文本类文件（代码、Markdown、JSON、CSV 等）会作为文本内容随消息发送
- 图片会自动压缩后以图像形式发送，适用于支持视觉的模型
- 其他二进制文件只发送文件名与大小

选中的文件会显示在输入框上方左侧，点右上角的叉可以移除。

## 七、外观

设置 → 颜色模式提供三种选择：**跟随系统 / 白色 / 黑色**。抽屉左下角的月亮、太阳按钮可以快速循环切换。

## 八、安全与隐私

- **传输加密**：请求通过 HTTPS 直接发送到你配置的服务端点，应用不经过任何中转服务器。允许 `http://` 是为了兼容本机与局域网模型，这类地址没有传输加密。
- **本地加密**：API 密钥、对话记录、统计数据使用 AES-256-GCM 加密后存放在应用私有目录，密钥由 Android KeyStore 生成并保管，其他应用无法读取。
- **无第三方统计**：应用不包含任何埋点、广告或数据上报。

密钥与系统绑定，卸载应用后无法解密还原，请提前备份需要的内容。

---

## 九、统计

设置 → 统计 可查看请求次数、输入 / 输出 / 总计 Token、缓存命中率，以及每个模型的分项数据。

缓存命中率取自接口返回的用量字段：DeepSeek 的 `prompt_cache_hit_tokens`、OpenAI 的 `cached_tokens`、Anthropic 的 `cache_read_input_tokens`、Gemini 的 `cachedContentTokenCount`。供应商不返回该字段时显示为 0%。

## 十、常见问题

**提示 401 认证失败**
密钥错误或已过期，重新复制一次密钥，注意不要带多余空格。

**提示 404 接口不存在**
Base URL 填错了。多数服务只需要填到域名，路径由应用补全。

**提示 400 未知参数**
供应商设置里把「参数风格」改成「都不发」。

**拉取模型列表为空**
部分服务不提供 `/models` 接口，手动逐行填写模型名即可。

**图片发送后模型说看不到**
当前模型不支持视觉输入，请换用多模态模型。

**搜索没有结果**
确认所选服务在本地网络是否可达；国内网络请使用 Bing 或 Baidu。
